# ABYX — ROOT CAUSE MATRIX & REMEDIATION PLAN

| Defect ID | Affected Component | Root Cause | Expected Behavior | Proposed Implementation Fix | Verification Test |
|---|---|---|---|---|---|
| **DEFECT-SEC-01** | `agent/tools/terminal_tool.js` | Parameter signature `runCommand({ command, cwd, timeout, shell, signal })` omitted `env`. Spreading `process.env` bypassed `SandboxManager.sanitizeEnvironment()`. | Child shell receives strictly sanitized environment allowlisting safe Windows variables (`PATH`, `SYSTEMROOT`, `TEMP`) while purging secrets. | Update `runCommand` signature to accept `env`. Construct a secure base environment allowlist; default to `this.getSanitizedEnv(env)`. | Inject `AUDIT_SECRET_API_KEY` into `process.env` and assert child shell `process.env.AUDIT_SECRET_API_KEY === undefined`. |
| **DEFECT-RUN-01** | `agent/execution_logger.js` | `ExecutionLogger` only implemented `constructor` and `scrub()`. `RuntimeController` expected `recordEvent(event)`. | Events recorded to in-memory history and persisted/scrubbed safely. | Add `recordEvent(event)` and `getEvents()` methods to `ExecutionLogger` class with secret scrubbing and event store synchronization. | Run `createAgentEngine().runtimeController.runSession()` with real local model and verify turn 1 completes without error. |
| **DEFECT-BRW-01** | `agent/tools/browser_tool.js` | `BrowserTool.interact()` had fallback `return { ok: true, simulated: true }` when Playwright was missing. | Tool returns real DOM interaction or explicit, actionable `ok: false, error: "Playwright required"`. | Strip simulated success response. Integrate headless Edge/Chrome CLI automation or return clean `ok: false` with installation guidance. | Run `browserTool.interact()` and verify `simulated` is never true. |
| **DEFECT-BRW-02** | `agent/tools/browser_tool.js` | `captureScreenshot()` only called `npx playwright screenshot`. | Screenshots captured via headless Edge/Chrome (built into Windows 11) or Playwright. | Add fallback to Windows built-in headless Edge (`msedge.exe --headless --screenshot=...`) when Playwright is absent. | Capture a live screenshot of `http://127.0.0.1:1420` and assert PNG output file exists and is non-empty. |
| **DEFECT-FS-01** | `agent/tools/fs_tool.js` | `FsTool` class lacked `renameFile`, `moveFile`, `copyFile` methods. | Full filesystem CRUD lifecycle supported with `PathGuard` containment. | Implement `renameFile({ from, to })`, `moveFile({ from, to })`, `copyFile({ from, to })` enforcing `PathGuard.resolveSafePath()` on both source and destination. | Execute rename, move, and copy tests on disposable fixtures within workspace. |
| **DEFECT-TST-01** | `agent/index.js` | Exports omitted `WorkspaceFsTool`, `ControlledBrowserTool`, `ControlledTerminalTool`. | `agent` package exports all required classes for test suites and consumers. | Export `WorkspaceFsTool: FsTool`, `ControlledBrowserTool: BrowserTool`, `ControlledTerminalTool: TerminalTool` in `agent/index.js`. | Execute `scripts/tests/stage12_harness_capabilities.test.cjs`. |
| **DEFECT-TST-02** | `scripts/tests/stage6_agent_capabilities.test.cjs` | Path `../../services/context_manager` broken after moving to `agent/`. | Test imports correct canonical path. | Update require to `../../agent/context_manager` (or provide compatibility export in `services/context_manager.js`). | Execute `scripts/tests/stage6_agent_capabilities.test.cjs`. |
| **DEFECT-TST-03** | `extensions/manifest_validator.js` & `agent/index.js` | `validateSchemaDefinition` not exported/defined in manifest validator; `ToolRegistry` export format. | Schema validator validates extension tool schemas properly. | Add `validateSchemaDefinition` function to `extensions/manifest_validator.js`; export class `ToolRegistry` properly. | Execute `scripts/tests/stage5_extensibility.test.cjs`. |
| **DEFECT-TST-04** | `agent/tools/fs_tool.js` / tests | Inconsistent method name: tests called `write()` while implementation was `writeFile()`. | Unified method aliases: `write` aliases `writeFile`, `read` aliases `readFile`. | Add `write(options)` alias for `writeFile(options)` and `read(options)` alias for `readFile(options)` on `FsTool`. | Execute `scripts/tests/workspaces_stage10.test.cjs`. |
| **DEFECT-TST-05** | `agent/tools/terminal_tool.js`, `policy_engine.js` | Inconsistent method name: tests called `terminal.execute()` and `policy.authorizeTerminalApiRequest()`. | Backward-compatible method aliases for clean test execution. | Add `execute(options)` alias for `runCommand(options)` on `TerminalTool`; add `authorizeTerminalApiRequest()` on `PolicyEngine`. | Execute `scripts/tests/stage1_security.test.cjs`. |
| **DEFECT-MEM-01** | `agent/memory/memory_manager.js` | SQLite build lacks FTS5 extension. | Search works seamlessly via structured queries and token matching when FTS5 is unavailable. | Ensure SQLite search falls back to parameter-bound SQL `LIKE` and tag indexing when `ftsEnabled` is false. | Execute search query on memory store with multiple entries. |
| **DEFECT-SKL-01** | `agent/skills/skill_engine.js` | Skills directory had no default built-in skills populated. | Built-in craftsmanship skills staged and loaded at startup. | Populate `agent/skills/` with core skills (`coding`, `security`, `documents`, `research`) and auto-discover on startup. | Query `/api/agent/skills` and verify non-empty list of available skills. |
| **DEFECT-BNCH-01** | `benchmarks/benchmark_runner.cjs` | Benchmark runner only ran 15 tasks; 260 tasks remained unexecuted in `catalog.json`. | Benchmark runner loads and executes real tasks from catalog with live agent runtime. | Implement automated benchmark execution loop for catalog tasks against real Abyx runtime. | Run benchmark suite and verify executed results in separate output directory. |
