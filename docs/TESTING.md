# Validation

Run the full repository validation command from the repository root:

```powershell
npm run validate
```

It runs the Node test suite and produces a frontend production build. A passing test proves only the behavior that test exercised. Live provider, browser, provider credential, and operating-system isolation claims require their own recorded runtime evidence.

Use `npm test` for the Node suite alone and `npm --prefix app/frontend run build` for the frontend build alone.
