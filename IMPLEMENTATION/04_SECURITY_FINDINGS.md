# Security Findings

Static risk assessment only; no penetration test or destructive execution. Primary runtime documentation confirms that Node's `vm` is not a security mechanism: [Node.js vm API](https://nodejs.org/api/vm.html). Node documents IncomingMessage `close` as request completion, not socket closure: [Node.js HTTP API](https://nodejs.org/api/http.html#event-close).

| Finding | Evidence and practical impact | Required gate |
|---|---|---|
| Shell policy and direct approval bypass (Critical) | Read-only patterns in `agent/policy_engine.js` accept suffix shell syntax. Safe classifier probe returned SAFE for `git status; echo POLICY_PROBE`; terminal `exec` interprets shell syntax. Also `/api/terminal/execute` executes commands whenever risk is anything other than `denied`, including `REQUIRES_APPROVAL`; the TerminalConsole calls this route. | Require explicit approval on every execution path; replace prefix allowlist; no command executes unless exact policy passes and OS sandbox boundary is active. Test both agent and direct terminal routes. |
| Filesystem symlink/TOCTOU (Critical) | `PathGuard.resolveSafePath` checks only immediate existing parent on missing targets. `fs_tool` checks then creates directories/files by pathname. Races and absent ancestor chains can escape intended root. | Canonical ancestor walk + safe handle operations; test symlink/junction and concurrent mutation. |
| “Sandbox” is not an OS boundary (Critical) | `provider_sandbox.js` uses `vm` for JavaScript and host Python subprocess; terminal only pins working directory. Both may inherit user capabilities. | Use platform-enforced isolation or mark as trusted local execution and require explicit user approval; never market vm as sandbox. |
| Process manifest PID reuse (High) | `process_lifecycle_manager.js::cleanupStaleProcesses` kills a recorded PID when PPID differs, without executable/start-time validation. A reused PID could belong to another process. | Validate owner, binary, creation time and app nonce before any kill; ambiguous entries are reported, not killed. Test with fake/corrupt manifests only in isolated process. |
| Local HTTP and wildcard CORS (High) | `serve.cjs::json` and `/api/agent/stream` return `Access-Control-Allow-Origin: *`; UI has no login; host override can bind beyond loopback. Exposes filesystem/model/automation APIs to web origins or LAN if configured. | Enforce Origin/Host allowlist and loopback token or authenticated remote mode; CSRF-safe methods; tests from hostile origin and LAN configuration. |
| MCP execution boundary (High) | Remote MCP configuration appears in tool schemas but no remote dispatcher exists. The only `calculate_or_eval` uses `vm` then Python. If alternate loop becomes live, its direct consumer dispatch bypasses canonical approval. | Implement actual MCP lifecycle only through ToolGateway; otherwise disable/label unsupported; isolate calculation. |
| Extension trust (High, currently disconnected) | `PluginRunner.loadPlugin` loads module into server process. Permission checks by name substring do not isolate module side effects. No active server integration call site found. | Keep disconnected until explicit trust model, OS boundary and capability-scoped API exist. |
| Approval wiring (High) | `requestAndExecuteTool` passes no `sessionId` into `PolicyEngine.evaluateToolCall`, so session grants are not consulted. The grant route accepts caller-supplied session IDs and arbitrary rule strings without authentication/ownership checks. The separate terminal route bypasses approval for `REQUIRES_APPROVAL` commands. | Define authenticated owner-bound grant schema, narrow rules, expiry/revocation and session propagation; enforce approval consistently on direct terminal API and agent calls. Do not expose wildcard grants through arbitrary strings. |
| Credential/log boundaries (Moderate) | Credential store and `ExecutionLogger.scrub` exist; scrub patterns are heuristic and different services log errors/arguments differently. | Structured secret fields, never log raw credentials, test variants, enforce retention and redaction centrally. |
| Browser cancel and untrusted content (Moderate) | Request timeout signal not forwarded by `ControlledBrowserTool.fetchPage`; public fetch helper does DNS/public-address work, but canceled work may persist. Web/document content must remain untrusted context. | Propagate cancellation through fetch/parse; hostile redirect/IP tests and prompt injection handling. |

No untrusted shell command, process kill, path race, plugin load, network fetch, model call or database mutation was performed. Severity reflects potential impact if relevant route is reachable, not exploitation evidence.
